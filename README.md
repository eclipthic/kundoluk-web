# Күндөлүк — веб-версия

Неофициальный веб-клиент для школьного дневника «Э-Күндөлүк» (Кыргызстан),
сделанный для использования на iPhone. Сервер работает на Render и проксирует
запросы к официальному бэкенду `kundoluk.edu.gov.kg`.

## Возможности
- Вход родителя (ПИН + пароль) и ученика.
- Список детей (для родителя) с выбором.
- Расписание уроков.
- Оценки по четвертям и за год.
- Домашние задания по четвертям.
- Уведомления (включая отсутствия) и отметка «прочитано».

## Локальный запуск
```sh
cargo run
# откройте http://localhost:3000
```

## Деплой на Render
1. Создайте репозиторий с этой папкой.
2. В Render: New → Web Service → подключите репозиторий.
3. Runtime: Rust (или Docker). Build: `cargo build --release`, Start: `./target/release/kundoluk-web`.
4. Render выдаст URL вида `https://kundoluk-web.onrender.com`.

## Прокси (важно)
Бэкенд `kundoluk.edu.gov.kg` отвечает только на IP из Кыргызстана. Если сервер
развёрнут за пределами KG, задайте переменную `KUNDOLUK_PROXY` (или `HTTPS_PROXY`)
с адресом HTTP/SOCKS5-прокси с кыргызским выходом:
```
KUNDOLUK_PROXY=http://USER:PASS@proxy.example.com:PORT
```
Проверить: `GET /api/ip` (должен показать KG-адрес) и `GET /api/test-upstream`
(должен вернуть 200).

## Примечание
Это неофициальный клиент. Использование стороннего клиента может нарушать
условия использования сервиса; входите только под своей учётной записью.
Пароль не сохраняется на сервере — передаётся только к официальному бэкенду.
